#  AutoParts Store — Backend API

Серверная часть системы управления каталогом автозапчастей. Написана на C++ с использованием кастомных алгоритмов сортировки и поиска для высокой производительности.

## 🛠 Технологический стек
* **Язык:** C++17
* **Networking:** cpp-httplib (REST API)
* **Data Format:** JSON (nlohmann/json)
* **Database:** Текстовые файлы в папке base/ (Flat-file DB)

---

##  Как запустить проект

1. **Склонируйте репозиторий вместе с зависимостями:**
   git clone --recursive <ссылка_на_ваш_репо>
   cd ARH_EVM

2. **Соберите и запустите сервер:**
   Мы подготовили скрипт, который сделает всё за вас (обновит либы, создаст папку сборки и скомпилирует):
   chmod +x setup.sh
   ./setup.sh

   Сервер поднимется на http://localhost:8080.

---

##  Архитектура и Алгоритмы

В проекте реализованы требования ТЗ через кастомные структуры:
1. QuickSort (Быстрая сортировка): Используется при запросе товаров. Все данные сортируются по ЦЕНЕ перед отправкой клиенту.
2. Дерево Оптимального Поиска (A1): Используется для мгновенного поиска товара по АРТИКУЛУ.
3. Целостность данных: При POST/DELETE запросах изменения синхронизируются с файлами в папке ../base/ в реальном времени.

##  API Эндпоинты

###  Категории (Categories)

- GET /api/categories — Получить список всех категорий (ID и Название).
- POST /api/categories — Создать новую категорию. Body: {"name": "Название"}.
- DELETE /api/categories/:id — Удалить категорию по ID.

###  Товары (Products)

- GET /api/products?categoryId=1 — Список товаров. Отсортированы QuickSort по цене.
- GET /api/search?article=ABC — Быстрый поиск по артикулу через дерево А1.
- POST /api/products — Добавить новый товар в категорию.
- DELETE /api/products/:article — Удалить товар по его артикулу.

## Примеры запросов (curl)

Добавление товара:
curl -X POST http://localhost:8080/api/products \
     -H "Content-Type: application/json" \
     -d '{"categoryId": 1, "name": "Тест_Деталь", "price": 500.0, "article": "TEST-123", "quantity": 5}'

Поиск товара:
curl http://localhost:8080/api/search?article=TEST-123
